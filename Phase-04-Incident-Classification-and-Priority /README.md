# Phase 4 — Incident Classification & Priority

## 📌 Overview

This phase focuses on classifying and prioritizing the Incident created in Phase 3.

Correct classification allows ServiceNow support teams to understand the nature of an incident, while Impact and Urgency are used to determine the appropriate Priority.

For this project, the reported corporate VPN connectivity issue is classified under the Network category and VPN subcategory.

The incident is assigned a Medium Impact and Medium Urgency, resulting in Priority 3 — Moderate.

---

## 🎯 Objective

The objectives of this phase are:

- Classify the Incident correctly.
- Select the appropriate Category.
- Select the appropriate Subcategory.
- Determine the business/technical Impact.
- Determine the required Urgency.
- Establish the Incident Priority.
- Validate that the Incident is ready for assignment and escalation.

---

# 🧑‍💻 Business Scenario

The Incident represents a corporate VPN connectivity problem.

The user is unable to connect to the organization's VPN.

Since the problem is related to network connectivity and specifically concerns VPN access, the Incident is classified as:

**Category:** Network

**Subcategory:** VPN
