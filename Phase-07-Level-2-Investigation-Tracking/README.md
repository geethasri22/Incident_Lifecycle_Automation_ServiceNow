# Phase 7 — Level 2 Investigation & Tracking

## 📌 Overview

This phase focuses on the detailed technical investigation performed by the Level 2 Network Support team after the Incident was escalated in Phase 6.

The corporate VPN connectivity Incident could not be completely resolved using the standard troubleshooting procedure available in the Knowledge Base.

The Incident was therefore transferred to Network Support and assigned to the network administrator.

In this phase, the Level 2 investigation is documented using ServiceNow Work Notes and Incident activity tracking.

The investigation identifies a VPN gateway configuration issue that requires a network-level configuration change.

---

## 🎯 Objective

The objectives of this phase are:

- Perform Level 2 technical investigation.
- Document investigation activities.
- Record findings using Work Notes.
- Identify the underlying technical issue.
- Determine the corrective action required.
- Maintain a complete Incident activity history.
- Establish the requirement for an Emergency Change Request.

---

# 👥 Level 2 Support

The Incident was escalated to:

**Assignment Group:** Network Support

**Assigned To:** network admin

The Level 2 team is responsible for performing detailed technical investigation after standard Level 1 troubleshooting is unsuccessful.
